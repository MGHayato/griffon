CPU どうしを 総当たりで 戦わせて、勝敗を かぞえた記録。

- **しらべた日**: 2026-09-04

- **やりかた**: `npm run preview` して `http://localhost:4173/?sim=all&n=50` を開く。
  結果は `window.SIM_RESULT.rows` に たまる。

## 相性表（先攻・後攻を あわせた 各100戦）

|---|---|---|---|---|
| 🗡️ **アリス** | — | **63%** ○ | 43% × | **82%** ◎ |
| 🍞 **ヘンゼル** | 37% × | — | 14% × | 39% × |
| 🍬 **グレーテル** | **57%** ○ | **86%** ◎ | — | **82%** ◎ |

◎ 65%以上 ／ ○ 55〜64% ／ × 45%未満

### 読みとれること

- **グレーテル → ヘンゼル は 86%**。いちばん 極端な 相性。
  回復とまもりで 粘られると、ヘンゼルの こまかい ダメージでは 押し切れない。
- **アリス → スノウ / グレーテル → スノウ が どちらも 82%**。
  スノウは 凍結で 足止めしても、そのあと 押し返す 打点が たりない。
- **スノウ → ヘンゼル だけ 61%** で 勝ち越している。
  ヘンゼルの 小さい ユニットは 凍らせると 何もできなくなる。
- **アリス vs グレーテル は 43% : 57%** で ほぼ 互角。ここだけ 拮抗している。

## 数字の たしかさ

50戦だと 勝率の ぶれは おおよそ **±7ポイント**。
なので 「82%」と「86%」の ちがいは 誤差の うちだけれど、
「75%」と「30%」の ような 大きな 差は 本物。

参考までに、10戦ずつで 2回 ためしたときは
グレーテル同型が 10-0 → 4-6 と 大きく ぶれた。
相性を 見るなら 50戦は ほしい。

## また しらべたいとき

```bash
npm run preview
```

そのあと ブラウザで：

| ひらく URL | やること |
|---|---|
| `?sim=all&n=50` | 16組 ぜんぶ × 50戦（9分くらい） |
| `?sim=all&n=10` | ざっと 見る（2分くらい） |
| `?sim=gretel,hansel&n=100` | 1組だけ こまかく |

途中の ようすは コンソールで `SIM_RESULT` を 見ると わかる。
`SIM_RESULT.finished` が `true` に なったら 終わり。

カードを いじったあとに もう一度 走らせて、
この表と くらべると 効きめが わかる。
