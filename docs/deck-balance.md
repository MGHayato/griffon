# デッキの 相性しらべ

CPU どうしを 総当たりで 戦わせて、勝敗を かぞえた記録。

- **しらべた日**: 2026-09-04
- **カード**: とくぎ19種 / どうぐ13種 / ユニット19種、1デッキ30枚
- **戦った数**: 16組 × 50戦 = **800戦**
- **毒**: どちらのターンが 終わっても 1ダメージ（1周で 2ダメージ）
- **やりかた**: `npm run preview` して `http://localhost:4173/?sim=all&n=50` を開く

> ひとつ前の 記録（毒が じぶんのターンの はじめに 1回だけ だったころ）は
> [`deck-balance-1-poison-once.md`](deck-balance-1-poison-once.md) に のこしてある。

### 毒の 変更で 動いたところ

- **ヘンゼル → グレーテル が 14% → 22%**。いちばん 大きく 動いた。
  ヘンゼルの 毒リンゴが 効くように なって、グレーテルの 回復を 上まわる 場面が 増えた。
- **アリス vs グレーテル が 48% : 52%** で ほぼ 五分五分に なった。
  ここが いちばん きれいな 勝負に なっている。
- **ヘンゼル vs スノウ が 45% : 55%**。毒を 持つ 両者の 対戦が 近づいた。
- **アリス → スノウ が 82% → 77%**。スノウの 毒リンゴが 効くように なったぶん。

ヘンゼルの 46% → 62% は そのまま 受けとらない ほうがいい。

## また しらべたいとき

```bash
npm run preview
```

そのあと ブラウザで：

| ひらく URL | やること |
|---|---|
| `?sim=all&n=50` | 16組 ぜんぶ × 50戦（9分くらい） |
| `?sim=all&n=10` | ざっと 見る（2分くらい） |
| `?sim=gretel,hansel&n=100` | 1組だけ こまかく |

途中の ようすは コンソールで `SIM_RESULT` を 見ると わかる。
`SIM_RESULT.finished` が `true` に なったら 終わり。
