# グリフォン（GRID FORMATION）

3レーンの陣形で戦う、CPU対戦のカードバトルゲーム。

公開先: https://claude.ai/code/artifact/39fc1bce-fc06-4773-9fd4-5026b4a9cb1d
（**このURLは変えない**。友達に共有ずみ）

---

## 起動のしかた

```bash
npm install     # 最初の1回だけ
npm run dev     # 開発サーバー起動 → 表示されたURLをブラウザで開く
```

`npm run dev` を動かしたままファイルを保存すると、ブラウザが**自動で更新される**。

| コマンド | 何をするか |
|---|---|
| `npm run dev` | 開発サーバーを起動。編集するとブラウザに即反映 |
| `npm run build` | 1ファイルに固めて `dist/` に出力（公開・配布用） |
| `npm run cards` | `card-names.md` の内容を `src/main.js` に反映 |
| `npm test` | ルールのテストを走らせる |
| `npm run watch` | テストを走らせ続ける（保存するたび再実行） |

## ファイルの役割

### ゲーム本体

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み。盤面・リーダー枠・手札の置き場所を定義している |
| `src/main.js` | **ゲームの中身ぜんぶ**。カード定義、ルール、CPU思考、描画、エフェクト |
| `src/style.css` | 見た目。RPGのコマンドウィンドウ風のデザイン |

> `src/main.js` は今1つのファイルだけど、これから
> `core`（ルール）/ `view`（描画）/ `ai`（CPU）に分けていく。
> 対人戦にはルールを画面から切り離すことが必要だから。

### カードとルールの管理

| ファイル | 役割 |
|---|---|
| `card-names.md` | **カードリスト**。名前・コスト・ステータス・効果・枚数。ここを編集する |
| `apply-cards.py` | `card-names.md` を読んで `src/main.js` のカード定義を書き換える |
| `rules-text.md` | 起動時に出るルール説明の文章 |

### ビルドまわり

| ファイル | 役割 |
|---|---|
| `vite.config.js` | ビルド設定。`vite-plugin-singlefile` で全部を1ファイルに固める |
| `scripts/make-artifact.js` | `dist/index.html` からArtifact公開用の `dist/griffon.html` を作る |
| `package.json` | コマンドと依存パッケージの定義 |
| `dist/` | ビルド結果（Git管理外。`npm run build` で作られる） |
| `node_modules/` | 依存パッケージ（Git管理外） |

### ドキュメント

| ファイル | 役割 |
|---|---|
| `roadmap.html` | **開発ロードマップ**。対人戦→アプリ化までの5フェーズ |
| `グリフォン_次にやること.md` | 再開するときの入口メモ |
| `README.md` | これ |

## カードを変えるとき

1. `card-names.md` の名前・コスト・ステータス・効果・枚数を書きかえる
2. `npm run cards` を実行（またはスラりんに「反映して」と言う）
3. `npm run dev` で確認

知らない書き方の効果が出てきたら、スクリプトは**何も壊さずに止まって**教えてくれる。
そのときはスラりんに言えば新メカニクスとして実装する。

## 公開するとき

```bash
npm run build
```

`dist/griffon.html` ができるので、それをArtifactに公開する（URLは変えない）。

## いま つかえる効果の 書きかた

| 書きかた | 意味 |
|---|---|
| `敵1体に◯ダメージ` | リーダーも ねらえる |
| `敵ユニット1体に◯ダメージ` | ユニットだけ |
| `敵全体に◯ダメージ` | 敵ユニット ぜんぶ |
| `縦1列に◯ダメージ` | えらんだ レーンの 前後2体（「縦一列」でもOK） |
| `横1列に◯ダメージ` | えらんだ ぜんれつ または こうれつの 3体 |
| `敵の縦1列の前後を入れ替える` | レーンの 前列と後列を 交換 |
| `敵1体に◯ダメージ、対象は次のターン攻撃できない` | 凍結（ダメージ＋足止め） |
| `敵1体は次のターン攻撃できない` | 凍結だけ（ダメージなし） |
| `味方1体を◯回復` | とくぎなら リーダーも えらべる |
| `味方全体を +◯/+◯` | 攻撃力とHPを 上げる |
| `味方1体の攻撃力を◯上げる` | 攻撃力だけ |
| `MPを◯回復` | そのターンだけ 上限を こえられる |
| `デッキの上から◯枚引く` | ドロー（「デッキから◯枚引く」でもOK） |
| `デッキからユニットを◯枚手札に加える` | サーチ |
| `デッキからコスト◯以下のユニットを◯枚手札に加える` | 条件つきサーチ |
| `デッキから特技を◯枚手札に加える` | とくぎだけ サーチ |
| `攻撃で与えたダメージ分、自分のHPを回復` | 吸血（持続） |
| `召喚したターンから攻撃できる` | 召喚酔いなし（持続） |

ユニットの効果に `召喚時：` を つけると 出したときに、
`死亡時：` を つけると やられたときに 発動する。

※ `死亡時：` で つかえるのは いまのところ サーチ・ドロー・MP回復・全体効果だけ。
　 対象を えらぶタイプ（`敵1体に◯ダメージ` など）は まだ未対応。

## ルール

- 相手リーダーの HP20 を けずりきったら 勝ち
- MPは 毎ターン 上限+1（最大10）、ターン開始で 全回復
- 盤面は たて3レーン × 前列・後列
- **ガード**：後列は 同じレーンの前列に なかまがいる間 こうげきされない
- **ブロック**：3レーンすべてに ユニットがいると リーダーを ねらえない
- とくぎは この2つを 無視できる
- ユニット同士が ぶつかると 攻撃側も はんげきを受ける
- 召喚した ターンは こうげきできない（ダッシュうさぎ などは 例外）
- ❄️が ついたユニットは つぎの じぶんのターンまで こうげきできない
