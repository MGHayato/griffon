# 絵を おくところ

ここに **カードの id と おなじ名前** で png を おくと、
そのカードの 絵文字が 手描きの絵に かわる。

おいていない カードは 絵文字のまま。
だから **1体ずつ 描いて すこしずつ** 入れかえられる。

```
art/dragon.png     → ドラゴンの絵に なる
art/slime.png      → スライムの絵に なる
```

おいたら 反映する：

```bash
npm run art
```

そのあと `npm run build` すれば ゲームに 入る。

---

## 描くときの 目安

**256 × 256 の png、背景は とうめい**（アルファつき）。
これで どの場所でも きれいに 出る。

絵は かならず **たてよこの 比を たもったまま** わくに おさまる。
つぶれることは ない。

| 出る場所 | わくの 大きさ | 画面が 2倍のとき |
|---|---|---|
| 長おしの 拡大 | 131 × 90 | 262 × 180 |
| 手札の カード | 72 × 46 | 144 × 92 |
| 盤面の ユニット | 34 × 34 | 68 × 68 |

わくの 形が 場所ごとに ちがうので、**どこかには 余白が 出る**。
絵を 大きくしても 余白は 減らない（形の ちがいなので）。

- **正方形（256×256）** … 盤面で ぴったり。手札と 拡大では 左右が あまる
- **よこ長（384×256）** … 手札と 拡大で ぴったり。盤面では 上下が あまる

盤面では 34px まで 縮むので、
**こまかい 描きこみより、輪郭が はっきりした かたち**の ほうが 映える。
いまの 絵文字と おなじくらいの 情報量が ちょうどいい。

## 大きさの こと

ゲームは 1ファイルで 配っているので、絵は ぜんぶ その中に 入る。
51種 ぜんぶ 入れると **200〜400KB ふえる** くらい。
遊ぶぶんには 気にならない 大きさだけれど、
もっと 軽くしたく なったら スラりんに 言えば まとめかたを 変える。

id が わからなく なったら：

```bash
npm run art -- --list
```
