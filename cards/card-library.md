# カードライブラリ

グリフォンに 出てくる カードを ぜんぶ ここに 書く。
**どのデッキが 何枚 使うかは、`card-アリス.md` などの デッキファイルで 決める。**
だから ここには 枚数を 書かない。

新しいカードは この表に 足すだけでいい。
どこかのデッキに 入れてはじめて 遊べるようになる。

## 効果の 書きかた

ここに ある書きかたなら そのまま 通る。
知らない書きかたを 書くと、反映のときに **止まって 教えてくれる**。
そのときは スラりんに 言えば 実装する。

### だれに あてるか

- **味方** … 盤面のユニット ＋ **リーダー**
- **味方ユニット** … 盤面のユニット だけ

回復や まもりは どちらでも 書ける。
攻撃力やHPを 上げるものは、リーダーに 攻撃力が 無いので
**ユニット だけ** に なる。

「敵」も おなじで、`敵1体` は リーダーも ねらえて、
`敵ユニット1体` は 盤面の子 だけ。

### ダメージ

| 書きかた | 意味 |
|---|---|
| `敵1体に◯ダメージ` | リーダーも ねらえる |
| `敵ユニット1体に◯ダメージ` | ユニットだけ |
| `敵全体に◯ダメージ` | 敵ユニット ぜんぶ |
| `縦1列に◯ダメージ` | えらんだ レーンの 前後2体 |
| `横1列に◯ダメージ` | えらんだ ぜんれつ または こうれつの 3体 |
| `凍結状態の敵全員に◯ダメージ` | こおっている子 だけ まとめて |
| `敵の縦1列の前後を入れ替える` | レーンの 前列と後列を 交換 |

### 状態異常

| 書きかた | 意味 |
|---|---|
| `敵1体を凍結させる` | こおらせるだけ |
| `敵◯体を凍結させる` | ◯回 えらんで こおらせる |
| `敵1体に◯ダメージ、対象を凍結させる` | ダメージ＋こおり |
| `横1列に◯ダメージ、対象を凍結させる` | 列ごと こおらせる |
| `敵ユニット全体に◯ダメージ、対象を凍結させる` | ぜんぶ こおらせる |
| `敵1体を毒状態にする` | 毎ターン 1ダメージ。とけない |

### 回復・まもり・強化

| 書きかた | 意味 |
|---|---|
| `味方1体を◯回復` | リーダーも えらべる |
| `味方ユニット1体を◯回復` | 盤面の子 だけ |
| `味方全体のHPを◯回復` | リーダーも ふくめて ぜんぶ |
| `味方ユニット全体のHPを◯回復` | 盤面の子 ぜんぶ |
| `◯ターンの間、味方1体が受けるダメージ-◯` | リーダーにも かけられる |
| `◯ターンの間、味方ユニット1体が受けるダメージ-◯` | 盤面の子 だけ |
| `◯ターンの間、味方全体が受けるダメージ-◯` | その あいだ ずっと |
| `味方ユニット全体を +◯/+◯` | 攻撃力とHPを 上げる |
| `味方ユニット1体の攻撃力+◯` | 攻撃力だけ |

### 手札・MP

| 書きかた | 意味 |
|---|---|
| `MPを◯回復` | そのターンだけ 上限を こえられる |
| `このターン中、どうぐのコスト-◯` | その ターンだけ 安くなる |
| `デッキの上から◯枚引く` | ドロー |
| `デッキからユニットを◯枚手札に加える` | サーチ |
| `デッキからどうぐを◯枚手札に加える` | どうぐだけ サーチ |
| `デッキから特技を◯枚手札に加える` | とくぎだけ サーチ |
| `デッキからコスト◯以下のユニットを◯枚手札に加える` | 条件つきサーチ |
| `使った道具をランダムに◯枚手札に加える` | 使いおわった どうぐを 拾う |
| `次のターン、敵は特技を使えない` | とくぎ封じ（どうぐは 使える） |

### ずっと つづく もちもの

`召喚時：` を つけない、その子が 持ちつづける 力。

| 書きかた | 意味 |
|---|---|
| `召喚したターンから攻撃できる` | 召喚酔いなし |
| `攻撃で与えたダメージ分、自分のHPを回復` | 吸血 |
| `攻撃するたびランダムな味方1体を◯回復` | 攻撃のたび 回復 |
| `凍結している敵の数だけコスト-◯` | こおった敵の数だけ 安くなる |

もちものの あとに `、召喚時：〜` を つづけて 書ける。
（例：`凍結している敵の数だけコスト-1、召喚時：縦一列に2ダメージ`）

---

ユニットの効果に `召喚時：` を つけると 出したときに、
`死亡時：` を つけると やられたときに 発動する。
