# カードライブラリ

グリフォンに 出てくる カードを ぜんぶ ここに 書く。
**どのデッキが 何枚 使うかは、`card-アリス.md` などの デッキファイルで 決める。**
だから ここには 枚数を 書かない。

新しいカードは この表に 足すだけでいい。
どこかのデッキに 入れてはじめて 遊べるようになる。

## 効果の 書きかた

ここに ある書きかたなら そのまま 通る。
知らない書きかたを 書くと、反映のときに **止まって 教えてくれる**。
そのときは スラりんに 言えば 実装する。

| 書きかた | 意味 |
|---|---|
| `敵1体に◯ダメージ` | リーダーも ねらえる |
| `敵ユニット1体に◯ダメージ` | ユニットだけ |
| `敵全体に◯ダメージ` | 敵ユニット ぜんぶ |
| `縦1列に◯ダメージ` | えらんだ レーンの 前後2体 |
| `横1列に◯ダメージ` | えらんだ ぜんれつ または こうれつの 3体 |
| `敵の縦1列の前後を入れ替える` | レーンの 前列と後列を 交換 |
| `敵1体に◯ダメージ、対象は次のターン攻撃できない` | 凍結 |
| `敵1体は次のターン攻撃できない` | 凍結だけ |
| `味方1体を◯回復` | とくぎなら リーダーも えらべる |
| `味方全体を +◯/+◯` | 攻撃力とHPを 上げる |
| `味方1体の攻撃力を◯上げる` | 攻撃力だけ |
| `MPを◯回復` | そのターンだけ 上限を こえられる |
| `デッキの上から◯枚引く` | ドロー |
| `デッキからユニットを◯枚手札に加える` | サーチ |
| `デッキからコスト◯以下のユニットを◯枚手札に加える` | 条件つきサーチ |
| `デッキから特技を◯枚手札に加える` | とくぎだけ サーチ |
| `攻撃で与えたダメージ分、自分のHPを回復` | 吸血（持続） |
| `召喚したターンから攻撃できる` | 召喚酔いなし（持続） |

ユニットの効果に `召喚時：` を つけると 出したときに、
`死亡時：` を つけると やられたときに 発動する。
